# Guardian Money CHF - PRD

## App Overview
Swiss personal finance app for iOS/Android with Expo + React Native.

## Modules
1. Auth & Onboarding - Login/Register with SHA-256, onboarding slides, canton selection
2. Dashboard - Patrimoine, Guardian Score, notifications, quick actions  
3. Dépenses - Daily/Pro/Contracts tabs with add/delete
4. Épargne - Savings goals with templates, auto-save, deposits
5. Swiss Tax Optimizer - IFD + ICC for 15 cantons, 3rd pillar optimization
6. Comparateur LAMal - 8 insurers, all franchises, subsidy calculator
7. Guardian Predict IA - Predictions, alerts, cash flow, insights, AI coach
8. Budgets - Category-based budget envelopes
9. Récurrents - Subscription management
10. Settings - Language, currency, data management
11. Subscription - Freemium with Pro upgrade

## Tech Stack
- React Native + Expo (Expo Router)
- Zustand + AsyncStorage for state
- All data stored locally (offline-first)
- Ready for Supabase integration
