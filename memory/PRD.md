# Guardian Money CHF v3.3 - PRD

## App Overview
Swiss personal finance app for iOS/Android with Expo + React Native.

## Key Updates v3.3
- ALL 26 Swiss cantons visible in LAMal comparator (grid layout)
- Beautiful SVG charts: Donut, Bar, Ring Progress, Sparkline
- Apple Pay + Google Pay + Samsung Pay added to payment methods
- 15 official insurer names from Priminfo 2026

## Modules
1. Auth - Supabase Auth + local fallback + Demo mode
2. Onboarding - 4 slides + 26 cantons + currency + goals
3. Dashboard - Charts: Donut by category, Monthly bars, Budget rings
4. Dépenses - Payment methods: Carte, Cash, TWINT, Apple Pay, E-Banking, PostFinance, LSV, Google Pay, Samsung Pay
5. Épargne - 12 templates, auto-save, deposits
6. Swiss Tax Optimizer - IFD + ICC, 3rd pillar
7. LAMal Priminfo 2026 - 15 assureurs, 26 cantons, all franchises, subsidies
8. Guardian Predict IA - Predictions, alerts, coach
9. Budgets, Récurrents, Dettes, Settings, Subscription Pro
